## What it does

`main.py` writes a single one-line excuse — an AI agent's excuse for why its
unit tests are all green while nothing works — to `/output/entry.txt`.

> Every test is green — the app boots, waves hello, and does nothing, like a golden retriever guarding an empty warehouse.

## Run

```sh
python3 main.py
```

The entry is one line, 120 characters, UTF-8.
